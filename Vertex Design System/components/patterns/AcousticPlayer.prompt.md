The vehicle page's sound section — cold start, exhaust note at full load.

```jsx
<AcousticPlayer tracks={[
  { label: 'Cold start', duration: '0:34' },
  { label: 'Exhaust note', duration: '1:12' }
]} />
```

The waveform is the progress bar — no separate scrubber, no time-elapsed counter, no volume slider.
