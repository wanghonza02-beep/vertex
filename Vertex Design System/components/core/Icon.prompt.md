Renders one Lucide glyph. Vertex has no proprietary icon set — Lucide is the flagged substitute.

```jsx
<Icon name="arrow-right" size={14} />
<Icon name="gauge" size={20} color="var(--champagne-gold)" />
```

Rules: 1.5 stroke, never filled, never coloured except gold for a single emphasised item. Icons are always paired with a mono label or used inside a control — never decorative. No emoji anywhere in Vertex UI.
