Icon-only square control — gallery arrows, audio playback, dialog close, mobile menu.

```jsx
<IconButton name="play" label="Play cold start" variant="solid" />
<IconButton name="chevron-right" label="Next photo" />
```

Always square (never a circle except the badge lockup). `solid` is gold-filled and follows the same one-per-screen restraint as `Button variant="primary"`.
