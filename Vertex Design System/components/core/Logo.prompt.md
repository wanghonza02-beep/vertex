The Vertex identity. Wordmark is always Italiana, 0.12em tracked, uppercase.

```jsx
<Logo variant="lockup" size={28} />
<Logo variant="badge" size={34} />
<Logo variant="mark" size={90} mono="gold" />
```

Clear space around the lockup = the height of the mark. Never place it on gold; never re-colour the two facets independently. Static SVG copies live in `assets/`.
